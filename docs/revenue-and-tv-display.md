# รายรับแพลตฟอร์ม และจอแสดงคิวบนทีวี

## 1) รายรับของแพลตฟอร์ม (หน้า `/super-admin`)

### ตัวเลขที่แสดง

| ตัวเลข | ความหมาย |
|---|---|
| รายรับรวมทั้งหมด | เงินที่ได้รับ **จริง** ทุกรายการตั้งแต่เปิดระบบ |
| รับเดือนนี้ | เงินที่ได้รับจริงในเดือนปฏิทินปัจจุบัน |
| รายได้ประจำ/เดือน (MRR) | ผลรวมราคาแพ็กเกจของคลินิกที่สถานะ ACTIVE และไม่ใช่แพ็กเกจฟรี = รายได้ที่คาดว่าจะเข้าทุกเดือน |
| คลินิกที่จ่ายเงิน | จำนวนคลินิกที่นับอยู่ใน MRR |
| ชำระแล้วรวม (ในตาราง) | ยอดสะสมที่คลินิกนั้นจ่ายมาทั้งหมด |

### ที่มาของข้อมูล — ตาราง `platform_payment`

- **Stripe (อัตโนมัติ):** Webhook `invoice.paid` บันทึกทุกครั้งที่ตัดบัตรสำเร็จ ทั้งรอบแรกและรอบต่ออายุ
  ใช้เลข invoice ของ Stripe เป็น `reference` (unique) จึงไม่บันทึกซ้ำแม้ Stripe ส่ง webhook มาหลายครั้ง
  → ต้องเพิ่ม event `invoice.paid` ในหน้า Webhook ของ Stripe Dashboard ด้วย
- **บันทึกเอง:** ปุ่ม "รับเงิน" ในตาราง สำหรับลูกค้าที่โอนเงินหรือจ่ายเงินสดนอก Stripe
  ลบได้เฉพาะรายการที่บันทึกเอง (รายการจาก Stripe ต้องคืนเงินผ่าน Stripe)

แยกจากตาราง `payment` เดิม ซึ่งเป็นเงินที่ **ผู้ป่วยจ่ายให้คลินิก** (ข้อมูลของแต่ละ tenant)

### ข้อมูลตัวอย่าง

ตอนเริ่มระบบ ถ้ายังไม่มีรายการรับเงินเลย จะสร้างรายการตัวอย่าง 6 รายการ (หมายเหตุ "ข้อมูลตัวอย่าง")
ปิดได้โดยตั้ง environment variable `SEED_DEMO_PAYMENTS=false` บน Render

### API (เฉพาะ SUPER_ADMIN)

| Method | Path | ใช้ทำอะไร |
|---|---|---|
| GET | `/api/super-admin/revenue` | สรุปรายรับ + ยอดรายคลินิก + 20 รายการล่าสุด |
| POST | `/api/super-admin/clinics/{id}/payments` | บันทึกรับเงินเอง `{ amountThb, method: BANK_TRANSFER\|CASH, paidDate, note }` |
| DELETE | `/api/super-admin/payments/{paymentId}` | ลบรายการที่บันทึกเอง |

## 2) จอแสดงคิวบนทีวี (`/queue/display`)

เปิดจากหน้า "คิวหน้าห้องตรวจ" → ปุ่ม **จอทีวี (ห้องนี้)** หรือ **จอทีวี (ทุกห้อง)**

| URL | แสดงผล |
|---|---|
| `/queue/display?doctor=5` | ห้องเดียว เลขคิวใหญ่เต็มจอ + คิวถัดไป 6 คิว |
| `/queue/display?doctor=all` | ทุกห้องพร้อมกัน (ห้องละการ์ด) |
| เพิ่ม `&names=hide` | ไม่แสดงชื่อผู้ป่วยเลย |

- อัปเดตทุก 5 วินาที ถ้าเน็ตหลุดจะแสดงข้อมูลล่าสุดค้างไว้และลองใหม่เอง
- ชื่อผู้ป่วยแสดงแบบปิดบางส่วน (เช่น "สมหญิง ใจ.") เพราะเป็นจอสาธารณะ (PDPA)
- เสียงเรียกคิว: เสียงกริ่ง + อ่านออกเสียงภาษาไทย "ขอเชิญหมายเลข เอ ศูนย์ หนึ่ง สอง ที่ห้องตรวจ 1"
  ดังเมื่อมีการเรียกคิวใหม่หรือกด "เรียกซ้ำ" (ต้องกดปุ่มเริ่มพร้อมเสียงก่อน เพราะเบราว์เซอร์ไม่ให้เล่นเสียงเอง)
- เป็นจอดูอย่างเดียว การเรียกคิวยังทำที่เครื่องเจ้าหน้าที่

### วิธีต่อขึ้นทีวี

1. **จอที่สองต่อกับคอมพิวเตอร์ (HDMI):** ตั้ง Windows เป็น Extend (Win + P) → ลากหน้าต่างจอคิวไปที่ทีวี → กดเริ่ม
2. **Smart TV / กล่อง Android TV:** เปิดเบราว์เซอร์บนทีวี → ล็อกอินด้วยบัญชีเจ้าหน้าที่ → เข้า `/queue/display?doctor=all`
3. **Chromecast / Screen Mirroring:** แคสต์แท็บจอคิวจาก Chrome ไปที่ทีวี

หมายเหตุ: token ล็อกอินมีอายุ 8 ชั่วโมง (`jwt-expiration-minutes: 480`) จอทีวีจึงต้องล็อกอินใหม่วันละครั้ง
แนะนำให้สร้างบัญชี STAFF แยกสำหรับจอทีวีโดยเฉพาะ
